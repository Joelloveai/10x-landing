# 10X Landing Page — Project Rules

## Design Constants
- Accent: #2563EB (blue)
- Background: #0A0A0A
- Surface: #111111
- Text: #FFFFFF
- Muted: #A1A1AA
- Font: Inter
- Border radius: 12px
- Section padding: 120px desktop / 64px mobile

## Copy Rules
- Never use: CRM, AI-powered, all-in-one, unlimited, seamless, robust, leverage
- No emojis
- No em dashes
- No exclamation marks
- Short sentences. One idea each.

## Technical Rules
- Next.js 16 App Router + TypeScript
- Framer Motion only (no other animation libraries)
- Tailwind CSS
- Respect prefers-reduced-motion
- Test with: npm run build
- All animations use transform/opacity only

## File Structure
- components/marketing/ — all landing page sections
- lib/ — data (testimonials, pricing, verticals)
- app/globals.css — global styles

## Token Efficiency
- Only read files explicitly mentioned in the task
- Do not explore the repo
- Do not read node_modules
- Do not run tests unless asked

## Response Format
- No preamble
- No summary
- Just: "Done." when complete@AGENTS.md
